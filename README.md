# 📊 HireMeMaybe

HireMeMaybe is a full-stack job tracking application designed to help users manage their job applications effectively. With HireMeMaybe, users can easily keep track of key details such as the position, company, status, and other important information about their job applications. The app provides a modern, responsive interface for managing job entries, offering essential features like adding, editing, and deleting jobs, as well as providing insightful data visualizations.

## 🚀 Features

- **Job Tracking:** Users can track job applications with details like position, company, status, and more.
- **CRUD Operations:** Easily create, update, delete, and manage job entries to keep the application data up-to-date.
- **Data Visualization:** Gain insights with interactive visualizations of job application data using Recharts.
- **User Authentication:** Secure user login and data protection powered by Clerk.
- **Data Management:** Uses Prisma with Supabase for reliable and efficient data storage and retrieval.
- **Form Validation:** Ensures data integrity and user input accuracy with Zod.

## 🛠 Technologies Used

- **Frontend:** Built with Next.js and styled using Tailwind CSS for a sleek and modern UI, enhanced by Shadcn components.
- **Backend:** Utilizes Prisma with Supabase for database management, providing a seamless data experience.
- **State Management & Data Fetching:** Integrated React Query for efficient data fetching, caching, and synchronization.
- **Authentication:** Secured with Clerk for user management and authentication.
- **Form Validation:** Robust form handling and validation with Zod.
- **Data Visualization:** Provides visual insights using Recharts.

## 📦 Getting Started

To get started with HireMeMaybe, clone the repository, install the dependencies, and run the development server:

```bash
git clone https://github.com/iluvcereals/HireMeMaybe.git
cd HireMeMaybe
npm install
npm run dev
```
